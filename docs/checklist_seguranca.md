# Checklist de segurança antes de cada envio ao GitHub

- [ ] Nenhum nome de organização, colaborador, instituição financeira, emissor, projeto ou convênio real
- [ ] Nenhum valor financeiro, percentual de carteira ou parâmetro de norma interna real
- [ ] Nenhum caminho de rede, SharePoint, URL interna ou e-mail no código ou nas planilhas
- [ ] Aba `Log` sem nomes de usuário reais
- [ ] Metadados limpos no Excel (*Arquivo → Informações → Verificar Problemas → Inspecionar Documento*)
- [ ] Nenhum logo, paleta ou fonte institucional
- [ ] Dados de exemplo gerados pelo script, nunca copiados de planilha real
- [ ] Nenhum arquivo real no computador dentro da pasta do repositório
- [ ] Repositório privado até haver autorização formal para torná-lo público
